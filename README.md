# Issue-SpecHelper

Issue-SpecHelper 是一款面向软件开发人员的 VS Code 插件，用于检查 GitHub Issue 描述质量，并对缺失的验收标准、复现步骤、预期结果和边界条件给出补全建议。

## 项目概览

- 课程：CS5351 软件工程
- 团队规模：8 人
- 开发周期：第 2-13 周，共 3 个 Sprint
- 技术方案：VS Code Webview + TypeScript 前端 + Python 后端 + 大模型 API
- 核心目标：跑通 Issue 文本输入、质量分析、检查结果展示和补全建议的端到端流程

## 每周记录说明

每位成员在对应周次下填写自己的记录。请尽量链接到 GitHub Issue、Pull Request、commit、测试结果或文档，作为最终报告中的个人贡献证据。

建议每条记录包含：

- 姓名与小组角色
- 本周完成事项
- 对应 Issue / PR / commit
- 测试或评审证据
- 投入工时或故事点
- 遇到的问题、风险和技术债务
- 下周计划

注意：不要在仓库中提交 API Key、GitHub Token、密码或其他密钥。
